# 12: AI 응답 시간 초과 대비

**What to build:** Apps Script는 외부 요청 하나를 기다리는 시간에 한계가 있다. 10번에서 응답이 느리면, 큰 반(35명)이나 긴 발표 기록에서도 실패하지 않도록 요청을 나누거나 재시도하고 안내 문구를 보강한다. 10번에서 충분히 빠르면 이 티켓은 닫는다.

**Blocked by:** 10번

**Status:** ready-for-agent

- [ ] 35명 반 조 편성, 10분 분량 기록 피드백이 시간 안에 끝난다(또는 나눠서 끝난다)
- [ ] 실패해도 이미 만든 결과는 잃지 않는다
- [ ] 교사에게 무엇을 다시 하면 되는지 안내된다
- [ ] 서버 테스트에 지연·실패 사례가 추가된다
