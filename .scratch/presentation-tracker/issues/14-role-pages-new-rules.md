# 14: 역할별 페이지와 새 역할 규칙이 맞물리는지 점검

**What to build:** v2에서 역할 규칙이 바뀌었다(데이터 엔지니어 2~3명 가능, 한 사람 최대 2개 역할, 빈 역할이 있는 채로 확정 가능, 교사의 학생 이동). 이런 경우에도 역할별 페이지의 "내 역할" 표시, 단계별 담당 안내, 최종 제출 권한이 의도대로 동작하는지 확인하고 필요하면 고친다. 예: 프로젝트 매니저가 없는 조는 지금 누구나 제출할 수 있다.

**Blocked by:** 03번

**Status:** done

- [x] 역할 2개인 학생은 두 역할의 페이지 모두에 "내 역할"이 표시된다
- [x] 데이터 엔지니어가 여러 명이어도 2단계 안내가 자연스럽다 (문구는 자연스러움. 엔지니어별 코랩 칸 문제는 15번으로)
- [x] 프로젝트 매니저가 없는 조의 제출 규칙을 교사와 정하고 그대로 동작한다
- [x] 이동으로 역할이 비워진 학생의 화면이 깨지지 않는다
- [x] 확인 결과를 서버 테스트에 추가한다

## 결과

- **교사 결정:** "최종 제출은 팀장만" 설정이 켜져 있으면, 팀장(프로젝트 매니저)이 없는 조는 교사가 팀장을 지정할 때까지 제출할 수 없다. 설정을 끄면 누구나 제출한다.
- 학생 제출 칸에 "팀장이 정해지지 않았어요" 안내. 교사 진행 현황에 "팀장 없음" 배지, 조 구성 화면에 경고, 조 확정 확인 창에 안내.
- 경고는 **조가 확정되어 작성 중일 때만** 보인다(역할 고르는 중·제출 완료 조에는 안 보임).
- 서버 테스트: 역할 2개 학생, 팀장 없는 조 제출 거부, 교사의 팀장 지정·해제, 설정 끄기, 팀장을 다른 조로 옮긴 경우, 경고가 뜨는 시점.
- 화면 확인(로컬): "내 역할" 표시, 학생 안내, 교사 경고와 지정 후 사라짐.
- 코드 검토(두 기준)에서 나온 것 중 경고 시점, 팀장 판단 중복, 팀장 이동 테스트는 고침. 활동지 설계 문제 두 가지는 15·16번으로 넘김.
