# 10: 실제 Gemini 연결 확인

**What to build:** 배포된 사이트에서 연습용 반으로 AI 조 편성안을 실제로 만들어, 실제 Gemini 키로 AI 기능이 동작하는지 확인하고 응답 시간을 잰다. 가능하면 발표 피드백과 세특 초안도 한 번씩 만들어 본다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] 연습용 반(예: 99반, 가상 학생 3~4명)으로 AI 조 편성안이 만들어진다
- [ ] AI 1차 피드백·세특 초안이 한 번씩 만들어진다
- [ ] 각 요청의 응답 시간을 기록한다(12번 판단 근거)
- [ ] 오류가 나면 화면 메시지를 그대로 기록한다
