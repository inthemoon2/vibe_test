# 05: 발표 실시간 기록

**What to build:** 교사 화면에서 조와 회차(1차/2차)를 고르고 녹음을 시작하면 말이 실시간으로 글이 된다(오디오는 저장하지 않음). 발언자 버튼(조원 + 교사)과 구간 버튼(발표·질의응답·피드백)을 누르면 그 뒤의 글이 해당 발언자·구간으로 기록된다. 녹음 중 자동 저장되고, 끝난 뒤 문단마다 구간·발언자·글을 고칠 수 있다. 음성 인식 부분은 나중에 클라우드 서비스로 바꿀 수 있게 분리한다.
