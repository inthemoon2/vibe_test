# 11: 실제 마이크 녹음 확인

**What to build:** 교실 노트북의 크롬이나 엣지에서 마이크를 허용하고 발표 기록을 실제로 해 본다. 한국어 인식 품질, 침묵 뒤 자동 재시작, 자동 저장, 발언자·구간 전환을 확인한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] 마이크 권한을 허용하면 말이 글로 나타난다
- [ ] 10초 이상 말이 없어도 녹음이 이어진다
- [ ] 녹음을 끝내면 기록이 저장되고 다시 열어도 남아 있다
- [ ] 교실 소음에서의 인식 품질을 메모한다
