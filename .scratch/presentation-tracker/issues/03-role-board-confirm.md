# 03: 역할 고르기와 조 확정

**What to build:** 조가 공개되면 학생 화면이 자기 조의 역할 고르기 화면으로 바뀐다. 학생은 자기 이름표를 역할 칸에 끌어다 놓는다(휴대폰은 버튼). 데이터 엔지니어는 최대 3명, 나머지 역할은 1명, 한 사람 최대 2개. 교사 화면에 빈 역할과 역할 없는 학생이 보이고, 교사가 조를 확정하면 역할이 고정되고 활동지가 열린다.

**Blocked by:** 02번

**Status:** done

- [x] 정원이 찬 칸이나 이미 2개 고른 학생은 화면과 서버 양쪽에서 막힌다
- [x] 다른 학생이 고른 결과가 몇 초 안에 화면에 반영된다
- [x] 빈 역할이 있어도 확정할 수 있다
- [x] 확정 후 학생은 역할을 바꿀 수 없고 교사만 고칠 수 있다
- [x] 확정되면 학생 화면이 저절로 활동지로 바뀐다
