# 00: 기존 활동지(역할별 6개 페이지)를 v2로 이어받기

**What to build:** v1에서 수업에 쓴 학생 활동지를 v2의 출발점으로 그대로 가져온다. 1~6단계 페이지마다 주로 맡는 역할이 있고(문제 정의: 프로젝트 매니저·도메인 분석가 / 데이터 수집·전처리: 데이터 엔지니어 / 모델 개발·평가: 모델 개발자 / 결과 분석·해결 방안: 도메인 분석가 / AI 윤리 점검: AI 윤리·소통 담당 / 나의 기여·발표 자료: 프로젝트 매니저), 팀홈에서 단계별 진행률과 "내 역할" 표시를 본다. 조원 누구나 모든 페이지를 쓰고, "나의 기여"는 본인만 쓴다. 차시별 점검, 채점(E1~E5), 가상채점, 보고서, 피드백 공개도 그대로 유지한다.
