# 01: 반별 명단과 개인 비밀번호 로그인

**What to build:** 교사는 반마다 학번·이름 명단만 올린다(조·역할 명단과 조 비밀번호는 없앰). 학생은 처음에 학번+이름으로 들어와 자기 비밀번호를 정하고, 이후 학번+이름+비밀번호로 로그인한다. 비밀번호를 잊으면 교사가 초기화한다.

- [x] 첫 로그인 학생에게 비밀번호 정하기 화면이 나온다
- [x] 틀린 비밀번호를 5번 넘게 입력하면 10분 동안 막힌다
