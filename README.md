# 사회문제 해결 기계학습 프로젝트 v2 — 발표 성장 기록 · 세특 도우미

고1 「인공지능 기초」 프로젝트용 학생 활동지 + 교사 관리 페이지입니다. 이미 수업에 쓴 v1을 복사해서 만든 새 버전이에요. v1과 시트·Apps Script가 완전히 분리되어 있습니다.

v2에서 새로 생긴 것:

- **개인 로그인**: 교사는 반별 명단(학번·이름)만 올리고, 학생은 첫 로그인 때 비밀번호를 직접 정합니다.
- **관심 분야 → AI 조 편성**: 학생이 진로·관심 분야를 쓰면, AI가 비슷한 분야끼리 조당 최대 5명으로 묶는 편성안을 만듭니다. 교사가 끌어다 놓기로 고친 뒤 공개합니다.
- **역할 고르기**: 학생이 자기 이름을 역할 칸에 끌어다 놓습니다. 데이터 엔지니어는 최대 3명, 나머지 역할은 1명씩이고, 한 사람이 최대 2개까지 맡습니다. 교사가 조를 확정하면 활동지가 열립니다. 학생 이동은 교사만, 언제든지 할 수 있습니다.
- **발표 기록**: 관리자 페이지에서 실시간 녹음 + 음성 인식으로 발표·질의응답·피드백을 글로 저장합니다. 오디오 파일은 저장하지 않습니다. 발언자와 구간은 버튼으로 표시합니다.
- **AI 초안 3단계**(모두 교사가 고치고 승인):
  1. 1차 피드백 정리 — 승인 후 학생 팀홈에 공개
  2. 2차 변화 서술 — 1차 → 피드백 → 2차 → 변화
  3. 세특 초안 — 기본 300자, 나이스 바이트 계산, 주의 단어 점검

설계 결정은 [.scratch/presentation-tracker/spec.md](.scratch/presentation-tracker/spec.md)에 있습니다.

## 설치 (처음 한 번)

### 1. 새 구글 시트 + Apps Script

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. v1 시트를 쓰면 안 됩니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 전체를 붙여넣습니다.
4. 왼쪽 **파일 +** → 스크립트 → 이름을 `V2`로 만들고, `apps-script/V2.gs` 전체를 붙여넣습니다.
5. 저장합니다.

### 2. 스크립트 속성

Apps Script 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성**에 추가합니다.

| 속성 | 값 | 필수 |
|---|---|---|
| `ADMIN_PASSWORD` | 관리자 페이지 비밀번호 | 필수 |
| `ANTHROPIC_API_KEY` | Claude API 키 ([console.anthropic.com](https://console.anthropic.com)에서 발급, 유료) | AI 기능에 필요 |
| `CLAUDE_MODEL` | 비우면 `claude-opus-5-5` | 선택 |

API 키는 서버(스크립트 속성)에만 저장되고 브라우저에는 보내지지 않습니다.

### 3. 웹 앱 배포

1. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
2. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 정합니다.
3. 배포하면 권한 승인 창이 뜹니다. 시트, 드라이브, 외부 서비스 연결(AI 호출) 권한을 허용하세요.
4. 나온 **웹 앱 URL**(`.../exec`로 끝남)을 복사합니다.
5. 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

### 4. 화면에 서버 주소 연결

`docs/config.example.js`를 복사해 `docs/config.js`를 만들고, `API_URL`에 3단계의 URL을 넣은 뒤 커밋·푸시합니다.

### 5. GitHub Pages 켜기

저장소 **Settings → Pages → Branch: `main`, 폴더: `/docs`** 로 설정합니다. 몇 분 뒤 나오는 주소가 학생 화면이고, 그 뒤에 `/admin.html`을 붙이면 교사 화면입니다.

> 이 저장소는 **비공개**입니다. 비공개 저장소의 Pages는 GitHub 유료 요금제(Pro 등)에서만 켤 수 있습니다. 무료 계정이라면 저장소를 공개로 바꿔야 합니다. 저장소에는 학생 정보가 없고, 학생 데이터는 모두 구글 시트에만 저장됩니다.

## 수업 흐름

1. **명단 · 비밀번호** 탭에 반별 명단(학번·이름)을 올립니다.
2. 학생이 학번 + 이름으로 로그인해 비밀번호를 정하고 진로·관심 분야를 씁니다.
3. **조 구성** 탭에서 진행합니다.
   1. 입력을 마감합니다.
   2. AI 조 편성안을 만듭니다("AI에 보내는 내용 보기"로 가명 처리를 확인할 수 있어요).
   3. 학생 카드를 끌어다 놓아 고칩니다.
   4. 학생에게 공개합니다.
4. 학생이 역할을 고르면 **조 확정**을 누릅니다. 이때 활동지가 열립니다.
5. **발표 기록** 탭에서 진행합니다.
   1. 조와 회차를 고르고 녹음을 시작합니다.
   2. 말하는 사람이 바뀌면 발언자 버튼을, 발표·질문·피드백이 바뀌면 구간 버튼을 누릅니다.
   3. 녹음이 끝나면 인식이 틀린 부분을 고칩니다. 특히 학생 이름이 틀리게 적혔으면 꼭 고치세요.
   4. AI ①로 1차 피드백을 정리하고, 승인한 뒤 공개합니다.
   5. 2차 발표를 녹음하고, AI ②로 변화 서술을 만들어 승인합니다.
6. **세특** 탭에서 조별 AI 초안을 만들고, 고쳐서 승인한 뒤 복사하거나 CSV로 저장합니다.

## 개인정보와 AI

- AI(Claude)에는 학생 이름과 학번을 **학생01** 같은 코드로 바꿔서 보냅니다. 녹음 글 속 이름(같은 반 학생 전체, 성을 뺀 이름 포함)도 바꿉니다. 결과는 서버에서 실명으로 되돌립니다.
- 음성 인식이 이름을 다르게 적으면(예: "서연" → "서현") 코드로 바뀌지 않습니다. 보내기 전에 기록을 확인하세요.
- **음성 인식(크롬 Web Speech API)은 소리를 구글 음성 인식 서버로 보내 글로 바꿉니다.** 이 앱은 오디오를 저장하지 않지만, 학교 지침에 따라 학생·학부모 안내가 필요할 수 있습니다.
- Claude API로 보낸 데이터는 기본적으로 모델 학습에 쓰이지 않습니다.
